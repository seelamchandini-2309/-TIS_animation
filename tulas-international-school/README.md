## Run Locally
Clone the repository:
```bash
git clone YOUR_REPOSITORY_URL
```

Go into the project:
```bash
cd tulas-international-school
```

Install dependencies:
```bash
npm install
```

Start development server:
```bash
npm run dev
```

The application will be available at:
`http://localhost:5173`

## Production Build
```bash
npm run build
```

Preview the production build:
```bash
npm run preview
```

## Deployment
The project can be deployed using Vercel.
- **Build command**: `npm run build`
- **Output directory**: `dist`

## Design Approach
The redesign combines the existing TIS identity with a modern editorial layout, large typography, strong green/yellow accents, rounded image containers and subtle motion.

The implementation intentionally keeps dependencies minimal and uses reusable React components instead of a large UI framework.
